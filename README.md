# Bieżnia Marcina

Apka na telefon (Chrome, Android), która łączy się z bieżnią przez Bluetooth (standard FTMS) i pokazuje prawdziwy dystans, tempo, prędkość, nachylenie i kalorie.

Adres: https://mluczak91.github.io/bieznia/

Dane biegów zostają w telefonie (pamięć Chrome + automatyczna kopia JSON w Pobranych). Nic nie jest wysyłane do tego repozytorium.
